# Risova - Enterprise CMMS (React + Vite)

Hệ thống Quản lý Bảo trì và Tài sản Doanh nghiệp tập trung.

## Giới thiệu & Cài đặt

Dự án cung cấp giao diện quản lý thiết bị, lệnh bảo trì (Work Orders), kho vật tư (Inventory), cảm biến IoT và hệ thống xác thực người dùng.

### Cài đặt môi trường:
```bash
npm install
npm run dev
```

### Các scripts hỗ trợ:
- `npm run dev`: Chạy server phát triển Vite.
- `npm run build`: Đóng gói ứng dụng cho môi trường production.
- `npm run lint`: Kiểm tra mã nguồn với ESLint.
- `npm run preview`: Xem trước bản build production.

---

This template provides a minimal setup to get React working in Vite with HMR, ESLint and Oxlint rules.

Currently, two official plugins are available:
- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)
